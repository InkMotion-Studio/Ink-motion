## 3. 本轮修复的真实缺陷（测试驱动发现）

| # | 缺陷 | 影响 | 修复 |
|---|---|---|---|
| D1 | `layout.contentHeight` 恒等于单列高度，未计入实际行数 | 自动滚动判定失效 | 重算 `contentHeight`（行数×行高）并新增 `contentWidth`（列数×列宽） |
| D2 | 竖排滚动模型错误：误按纵向滚动 | 长文滚动方向不符竖排语义 | 改为**横向滚动**（内容自右向左，书写头保持在可视区） |
| D3 | `Scene.snapshot`/`drawFrame` 无 canvas 上下文守卫 | 隐私模式/无 canvas 环境抛错 | 增加 `getContext('2d')` 空值守卫，返回 null |

## 4. 性能优化（N4.3）

- **字体天然子集化**：笔画数据按字懒加载，首屏体积与文本长度无关；>800 唯一字时给出说明。
- **长文降帧与分块** `lib/perf.ts`：
  - ≤300 字：全速
  - 301–1500：降至 24–30 fps
  - >1500：锁 24 fps + 每 200 字让出主线程（保 5000 字可导出）
- **构建体积**：JS 340KB / **gzip 113KB**（含 React/Router/Zustand/Dexie/Hanzi-Writer 客户端/mp4-muxer），符合首屏预算。

## 5. 无障碍（N4.4，WCAG 2.1 AA 目标）

| 项 | 落地 |
|---|---|
| 键盘可达 | 全组件 `:focus-visible` 焦点环；Modal 焦点陷阱 + Esc 关闭 + 关闭后焦点归位 |
| 跳转链接 | `.im-skip-link` 跳到主内容（2.4.1） |
| 语义 | `role=dialog`/`aria-modal`、`aria-live` 状态、`aria-invalid`+`role=alert` 错误 |
| 表单 | label 与控件 `htmlFor/id` 关联 |
| 动效 | `prefers-reduced-motion` 尊重系统设置 |
| 对比度 | 墨 `#1c1a17` / 宣纸 `#f4ecd8` 对比度约 14:1，远超 AA 4.5:1 |
