## 2. 关键前提：外部依赖重大变化（本轮规划的决定性输入）

> **这是 V1.0 与原 IM-PLAN-001 §3.2 判断产生分歧的核心。原计划中"V1.0 古文字路径阻塞于字体资产"的前提已不再成立。**

### 2.1 Unicode 18.0 已发布，小篆获得独立编码
- 发布时间：**2026-09-16**（原规划编制时仍为"未发布"状态）。
- 新增 **Seal（小篆）区块：U+3D000–U+3FC3F，共 11,328 码位**，取自《说文解字》四版本（THX/CCZ/QJZ/DYC）。
- 意义：篆字从此拥有脱离 CJK 统一表意文字的独立码位，**可按码位直接寻址字形**，无需再依赖"骨架化推测"。

### 2.2 霞鹜篆书（LXGW Seal）已开源
| 项 | 值 |
|---|---|
| 仓库 | github.com/lxgw/LxgwSeal |
| 授权 | **SIL OFL 1.1**（可商用、可嵌入、可再分发，须附 OFL.txt；保留名称"霞鹜/LXGW"） |
| 当前字数 | **165 篆字**（2026-10-08 扩充；2026-07 首版 45 → 2026-10 达 165） |
| 映射 | 每个篆字设 Unicode 18.0 小篆码位，**并含对应今字映射**（如 U+3ECA3 ↔ 獻/献） |
| 正式版计划 | **已缩减为 200 余字**（原计划 300），删减二十八宿/八卦等低频字；**完成后不再维护** |

### 2.3 其他可用开源/开放字源（备选）
| 字体 | 授权 | 字数 | 备注 |
|---|---|---|---|
| 敬峰中山王篆 | OFL | ~2832（简体）/ 2072（繁体） | 战国中山王风格，含《道德经帛书本》《小学必背古诗》覆盖 |
| 全字库说文解字 | 台湾地区政府资料开放授权（可商用） | 6721 | 说文小篆风格，无标点/字母 |

### 2.4 对规划的影响（结论）
| 原判断（IM-PLAN-001） | 新判断（本文档） |
|---|---|
| 古文字路径 V1.0 **阻塞**，推 V2.0 备选 | 古文字路径 **V1.0 可交付**，但**必须限定为"受限字库"模式**（预设字表，非任意文本） |
| 依赖"开源小篆发布"这一不确定事件 | 依赖已满足，风险从"可否实现"转为"字库覆盖率与扩充策略" |
| 骨架化（MAT/Zhang-Suen）为主要手段 | **改为：优先直接使用真实篆字字形（含今字映射）**；骨架化降级为可选增强/兜底 |

> **重要设计决策 D-V1-01：** 古文字路径从"骨架化模拟"**转为"受限字库 + 真实字形映射"**。这既符合 IM-BASELINE-001"古文字=受限字库，非任意文本"的原始约束，也规避了骨架化质量这一高 R&D 风险（原 R-03）。

## 3. V1.0 交付范围定义

### 3.1 在范围内（V1.0）

| 维度 | 内容 | 依据 |
|---|---|---|
| **古文字路径** | 小篆（霞鹜篆书 165+ 字，受限字库）；越界字符跳过并提示 | 重评结论 §2.4 |
| **隶书路径** | 评估后决定：若字源不足则并入 V1.1（见 §8 待确认 TBD-V1-03） | 待定 |
| **模板库页** | 预设模板扩展为独立页面（含分类、预览） | 原 §3.2 |
| **帮助页** | 使用指南、快捷键、FAQ、隐私说明 | 原 §3.2 |
| **深色主题** | 启用 `tokens.css` 预留的 dark 变量，全站适配 | 原 §3.2 |
| **英文 i18n** | zh/en 双语骨架（UI 文案抽取 + 切换） | 原 §3.2 |
| **字体上传** | 用户本地字体导入（IndexedDB 存储 + FontFace 注册） | 原 §3.2 |
| **4K 导出** | 2160×3840 画布规格 | 原 §3.2 |
| **导出增强** | 进度可取消、导出队列（多任务） | 本轮新增 |
| **无障碍深化** | 键盘全流程、屏幕阅读器标签完善、对比度审计 | 本轮新增 |

### 3.2 不在范围内（推 V2.0）

- 金文/甲骨文（字源不成熟）
- Three.js/WebGL 3D 载体（甲骨/青铜/石碑）
- 透明背景（ffmpeg.wasm）
- 匿名埋点（需授权合规评审）
- 插件市场（PluginLoader）、SDF 缓存
- 隶书路径若字源不足则推 V1.1
