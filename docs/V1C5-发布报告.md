## 2. N5.1 部署更新（资产 `inkmotion-assets-v2`）

### 2.1 资产命名空间与缓存版本化

| 项 | V1.0 前 | V1.0 |
|---|---|---|
| 命名空间 / 缓存名 | `inkmotion-assets-v1` | **`inkmotion-assets-v2`** |
| 资产清单条目 | 2（纹理 ×2） | **6**（纹理 ×2 + 小篆字体/字表/许可 + 回退 TTF） |
| 历史缓存 | 无清理 | **`purgeLegacyAssetCaches()` 启动时自动清理 v1** |
| 小篆字体回退 | 无 | **子集 woff2（42KB）→ 完整 TTF（223KB）自动回退** |

### 2.2 修复的真实缺陷

- **同源部署资产 URL 误拼**：此前未配置 CDN 时，`assetUrl()` 会拼出 `/inkmotion-assets-v1/textures/paper.png`，而静态产物实际位于 `/textures/paper.png`，导致启动预缓存**全部 404（静默失败、离线能力名存实亡）**。现改为：未配置 `VITE_ASSET_CDN` 时直接引用 `public/` 相对路径；仅 CDN 模式加命名空间前缀。
- **CDN 前缀逻辑重复实现**：`textures.ts` 与 `assets.ts` 各写一份前缀拼接，现统一由 `assets.ts` 资产清单提供。

### 2.3 部署配置

| 平台 | 文件 | 配置 |
|---|---|---|
| Netlify / CF Pages | `public/_headers` | `/assets/*` 与 `/fonts/seal/*` immutable 长缓存；`/textures/*`、`/fonts/*` 30 天；安全头 + `Permissions-Policy` |
| Vercel | `vercel.json` | 同源策略（headers 段） |
| 通用重定向 | `netlify.toml` | SPA 回退 + 安全头 |
| 构建 | `vite.config.ts` | `assetsInlineLimit: 4096`（字体不内联为 data URI，保证独立缓存与许可随附） |

### 2.4 文档

`docs/IM-OPS-001` 升 **v1.1**：新增资产清单表（§6.1）、同源/CDN 双模式说明（§6.2）、多平台缓存与安全头（§6.3）、回滚补充、发布检查单扩至 **O1–O9**。

## 3. N5.2 许可合规扩展

### 3.1 许可登记单一真源

新增 `src/lib/licenses.ts`，关于页、发布检查单、仓库 `THIRD-PARTY-NOTICES.md` 同表渲染，杜绝署名遗漏：

| 类别 | 条目 | 许可 | 署名要求 |

- 仓库新增 **`NOTICE`**（Apache 惯例）与 **`THIRD-PARTY-NOTICES.md`**（字体/组件许可、合规动作、用户上传字体责任说明）。
- i18n：zh/en **各新增 10 条**词条（许可 + 浏览器兼容性），英文包键集合与中文完全一致（单测断言）。

- CI：`.github/workflows/deploy.yml` 增 `npm run test` 与随包许可文件存在性校验（`NOTICE`、`THIRD-PARTY-NOTICES.md`、`public/fonts/seal/OFL.txt`）。

### 3.3 TBD-V1-04 决策（4K 目标浏览器）

**决策：以 Chromium 桌面版（Chrome / Edge 新版）为 4K 验证目标**。Safari 新版走 MP4、Firefox 走 WebM 保底；4K 需约 33MB 画布内存，内存受限设备自动降帧或失败，帮助页明确建议改用 1080×1920。该结论已写入中英文帮助页并由 E2E 断言覆盖。
