## 4. 测试环境（V2.0 增量说明）

浏览器矩阵沿用 IM-TEST-V1-001 §4（Chrome/Edge 94+、Firefox 130+、Safari 26+），V2.0 增加三条执行要求：

| 新增要求 | 说明 |
|---|---|
| **字源分层须在三浏览器各跑一遍** | L1/L2 字体子集化产物在不同浏览器 FontFace 解析差异 |
| **描边动画须在三浏览器各跑一遍** | opentype.js 轮廓解析 + Canvas/SVG 描边跨浏览器一致性 |
| **4K 导出矩阵补全** | Safari（MP4）、Firefox（WebM 保底）、Chromium（双通道）4K 实测，非仅 Chromium |
