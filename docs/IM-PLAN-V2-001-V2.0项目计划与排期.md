## 3. V2.0 交付范围定义

### 3.1 在范围内（V2.0）

| 维度 | 内容 | 依据 |
|---|---|---|
| **篆书字源分层** | L0 霞鹜（保底）+ L1 敬峰中山王篆（主力，~2832 字）+ L2 全字库说文解字（**已决策纳入 V2.0**，6721 字）；合并映射与优先级回退 | IM-GLYPH-V2-001 §3 |
| **覆盖率提升** | 篆书常用字覆盖从 165 → 约 2832；生僻字经 L2 覆盖 | VR-01 |
| **书体扩展** | 隶书路径（字源合规确认后）；复用整字显现渲染 | TBD-V1-03 |
| **古文字动画** | 可选轮廓描边动画（沿字形轮廓描绘，不承诺笔顺） | TBD-V1-02 |
| **国际化深化** | 英文 i18n 母语审校；多语言包结构完善（zh/en 全量审校通过） | TBD-V1-05 |
| **导出兼容深化** | 4K 在 Safari/Firefox 的验证与降级策略；跨浏览器导出矩阵补全 | VR-06/VR-10 |
| **资产与发布** | 命名空间升至 `inkmotion-assets-v3`；版本号 2.0.0；许可署名扩展 | 沿用 V1-C5 模式 |

### 3.2 不在范围内（推 V2.1+）

- 金文/甲骨文（字源不成熟）。
- 三层之外新增书体（行/草/楷变体），除非 V2-C2 Spike 发现高价值低成本的方案。
- L2 全字库已纳入 V2.0（用户决策 2026-10-14，TBD-V2-01 关闭），仍严格按需加载、独立缓存、不计入首屏（VR2-05 技术约束保留）。
- 隶书依合规政策 D-V2-02「一律采用 + 授权待办登记」推进，不再以合规确认作为阻塞（TBD-V2-02 关闭）。
- 透明背景、3D 载体、插件市场等 V1.0 已明确推后的方向。

## 6. 与 V1.0 交付方式的一致性

| 维度 | V1.0 做法 | V2.0 做法（一致） |
|---|---|---|
| 检查点交付 | 每检查点打包可运行 zip | 同 |
| 零上传隐私 | 文本/字体永不离开浏览器 | 同（字源仍走静态资产，无上传） |
| 资产命名空间 | `inkmotion-assets-v2` | 升至 `inkmotion-assets-v3`（向后清理 v2 旧缓存） |
| 许可合规 | OFL 署名 + NOTICE/THIRD-PARTY | 扩展（新增敬峰/全字库/隶书/opentype.js 署名） |
| 质量门禁 | 单测/E2E/axe/体积预算 | 同，并新增字源分层/4K 跨浏览器用例 |

> **合规政策 D-V2-02（用户决策 2026-10-14）：** V2.0 不再以"资源合规性"作为功能阻塞条件——对评估范围内字源**一律采用**；对需授权/授权待确认的字体，统一登记于「字体授权待办登记册」（`PENDING-LICENSES.md` 与 `src/lib/licenses.ts` 的 `pendingAuthorization` 字段），供后续联系作者/权利方获取正式授权。该政策将 VR2-02（隶书字源授权）由"高·阻塞"降级为"已接受·低"，TBD-V2-02 据此关闭。

> **字体选型政策 D-V2-03（用户决策 2026-10-14，V2-C2 验收）：** 字体**优先采用开源社区优秀项目**，以"先用起来"为第一原则，暂不以商用合规为选型前提——即：字源/字体选型优先考量**开放许可（OFL 等）、社区口碑与字形质量**，合规风险通过 D-V2-02 的「字体授权待办登记册」统一登记后置处理，不作为功能阻塞。隶书及后续字源均按此政策落地。
