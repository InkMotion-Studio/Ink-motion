## 1. 审校目标（TC-V2-I18N-01）

V1.0 的英文包为**骨架占位**（i18n.en.ts 头部原注：「未经母语审校」）。V2-C3 N3.1 对全量英文文案执行**母语级审校**，目标：

1. 消除逐字直译与机翻痕迹，采用地道英文表达；
2. 术语统一（书体、字源、路径、载体等专名）；
3. 语气一致（对外说明用客观、简洁的陈述句）；
4. 与中文语义对齐，不增不减信息。

---

## 2. 执行方式（TBD-V2-05 结案）

| 项 | 决策 |
|---|---|
| 执行方式 | **母语级人工审校 + 工具辅助**（TBD-V2-05 建议项落地） |
| 审校人 | 英文文案审校（母语级撰写） |
| 工具辅助 | `node scripts/check-i18n.mjs`（键集合一致性 + 占位符对齐 + 硬编码扫描） |
| 门禁固化 | N3.3：脚本接入 `npm run check:i18n`，文案变更须过检 |

> **TBD-V2-05 结论**：采用**母语级人工审校为主、脚本校验为辅**；不引入外包流程（成本高于本阶段收益）。脚本固化为持续门禁，防止后续回归。

## 3. 主要修订（代表性样例）

| 键 | 修订前（V1.0 骨架） | 修订后（V2-C3 审校） | 修订理由 |
|---|---|---|---|
| `app.tagline` | A pure-frontend classical Chinese video generator. Vertical right-to-left writing… | A **browser-only** classical Chinese video generator. Vertical right-to-left text… so your text never leaves your device. | "pure-frontend"→"browser-only" 更自然；"writing"→"text" 更准确；末句补足隐私卖点且更流畅 |
| `help.seal` | limited library (~165/238 chars)… no stroke animation | a limited library (**about 165 of 238 characters**)… with **no stroke-by-stroke writing** | "~165/238" 不宜作英文表达；"no stroke animation" 语义过宽（易误读为"无动画"）→ 精确为"no stroke-by-stroke writing" |
| `help.li` | charset grows **by version** | the charset **grows with each release** | "by version" 生硬 → 地道表达 |
| `export.capNote` | （WebM 保底 / MP4 增强，自动降级） | (WebM fallback / MP4 enhanced, **with automatic downgrade**) | 补足主语与连接词，符合英文技术文案习惯 |
| `options.font.kai` | Regular (precise strokes) | Regular (**precise stroke order**) | "strokes"→"stroke order" 更贴合"笔顺"原意 |
| `settings.fonts.tip` | max 8MB per file | **up to {mb} MB** per file | "max 8MB"→"up to …"；并参数化 MB 值（与源码常量绑定） |
| `about.pendingLicense.note` | …logged **for follow-up authorization contact**. | …logged here **so we can follow up with the rights holders**. | 消除名词堆叠，改为自然从句 |

> 全量逐条差异见 git 记录 `src/lib/i18n.en.ts`。审校以**可读性与准确性**为准，不追求与中文逐字对应。
