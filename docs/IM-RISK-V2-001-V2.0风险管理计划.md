## 2. 本文件与 IM-RISK-V1-001 的关系

IM-RISK-V1-001 是 **V1.0 全周期**风险登记册，R-01 已关闭、R-03 已降级，VR-01~VR-10 随 V1.0 交付完成闭环。本文件：

4. **重绘** V2.0 风险矩阵与跟踪机制。

> 编号规则：V1.0 风险沿用 `VR-xx` 并标注 V2 状态；V2.0 新增风险使用 `VR2-xx`，避免与既有编号冲突。

## 5. V2.0 新增风险（VR2 系列）

### VR2-01 字源分层合并复杂度 `[技术·中]`

| 项 | 内容 |
|---|---|
| 描述 | 三源（霞鹜/敬峰/全字库）码位映射合并时可能产生冲突；不同风格混排视觉不一致 |
| 影响 | 映射错误或视觉冲突导致内容不可信 |
| 缓解 | 明确优先级（L1→L0→L2）；合并字表 `seal-map-v2.json` 单源优先；GV-V2-02 正确率 ≥ 99% 门禁；混排以 L1 为主体风格 |
| 触发 | 合并映射抽样正确率 < 99% |

### VR2-02 隶书字源授权不清 `[合规·高]` → **降级为「已接受·低」（D-V2-02）**

| 项 | 内容 |
|---|---|
| 原描述 | 候选隶书字体授权需逐一核验；若无法确认 OFL/开放授权，则不能上线（V1.0 许可红线） |
| **降级依据（D-V2-02，用户决策 2026-10-14）** | V2.0 不再以资源合规为功能阻塞：对评估范围内字源**一律采用**；需授权/授权待确认的隶书字体统一登记于「字体授权待办登记册」（`PENDING-LICENSES.md` + `src/lib/licenses.ts` 的 `pendingAuthorization`），由用户后续联系作者/权利方获取正式授权。TBD-V2-02 据此关闭 |
| 残留跟踪 | 登记册须随 V2.0 发布交付；发布报告标注"部分字体授权待确认" |
| 触发 | ——（已接受，转为登记册跟踪） |

### VR2-03 描边动画矢量供给 `[技术·中]` → **已闭环·低**

| 项 | 内容 |
|---|---|
| 描述 | 描边动画依赖解析字体轮廓；若字源轮廓异常或解析失败，动画无法生成 |
| 影响 | 描边功能不可用或部分字形异常 |
| 缓解（V2-C2 落地） | **改为自研轻量 TTF 解析**（`src/engine/outline.ts`，否决 opentype.js 的 ~80KB，守 gzip<200KB 门禁）；仅覆盖 TrueType 简单/复合轮廓；解析失败**静默返回 null → 降级整字填充**（V1.0 行为，不白屏、不抛错），日志 `console.debug` 非 error；仅 seal/li 生效 |
| 实测 | 自研解析 +~2.75KB gzip（123.95→126.70KB）；合成 TTF 单测验证 bbox/周长/曲线展平正确 |
| 触发 | ~~轮廓解析失败率 > 1%~~ → 已由降级契约兜底，不再构成阻塞 |

### VR2-04 英文审校质量与进度 `[质量·中 → 已关闭]`

| 项 | 内容 |
|---|---|
| 描述 | 英文文案母语审校需协调资源；若审校不充分，V1.0 的"骨架占位"问题未根治 |
| 影响 | 英文用户体验降级，TBD-V1-05 未真正闭环 |
| 缓解（V2-C3 落地） | **完成母语级人工审校**（zh/en 各 252 键全量对齐，含变量插值一致性）；**N3.3 固化审校门禁**：`npm run check:i18n` 三重静态校验（键集合一致 / 取值非空 / 占位符集合一致 + 硬编码中文扫描）接入 CI（`deploy.yml`），文案变更须过门禁；审校记录入库 `docs/IM-I18N-V2-001`；运维流程固化见 `IM-OPS-001 §8bis` |
| 实测 | 审校完成率 **100%**（252/252）；`check:i18n` 通过；E2E `v2c3.mjs` 12/12、`release-check` V2-C8 三项全绿 |
| 触发 | ~~审校完成率 < 100% 即发布~~ → **已达成 100%，风险关闭**（TBD-V1-05 / TBD-V2-05 同步关闭） |

### VR2-05 L2 体积污染首屏 / 缓存容量 `[技术·中]`

| 项 | 内容 |
|---|---|
| 描述 | 全字库 6721 字子集化后仍可能体积较大；若误入首屏或超缓存上限（IM-DB-001 §6 ≤200MB），影响性能 |
| 影响 | 首屏体积回升（R-04）或缓存溢出 |
| 缓解 | L2 严格按需、独立缓存、不计入首屏；TBD-V2-01 评估是否纳入 V2.0；TBD-V2-04 体积核验 |
| 触发 | 首屏 gzip 超预算 或 缓存占用 > 200MB |

### VR2-06 描边动画性能 `[技术·低]`

| 项 | 内容 |
|---|---|
| 描述 | 大量字形同时描边动画可能导致帧率下降 |
| 影响 | 长文/4K 场景卡顿 |
| 缓解（V2-C2 落地） | 描边**默认关闭**（`outlineAnimation=false`）；关闭或非受限路径时**零解析开销**；开启后按需预解析并按 100 字分块让出主线程；解析失败降级整字填充 |
| 触发 | ~~60fps 目标下降 > 20%~~ → 关闭态零开销，开启态分块预解析，风险降至低 |
