## 2. 引言

### 2.1 目的

本文档定义"墨演 InkMotion"的测试策略与用例，确保 MVP/V1.0 交付符合已批准规格、基线与《IM-RISK-001》登记的风险缓解要求。

### 2.2 测试范围

| 在范围内 | 不在范围内 |
|---|---|
| 引擎（排版/笔画/载体/导出）单测与集成测 | 第三方库内部实现 |
| UI 流程 E2E（首页/编辑器/项目/设置） | 视觉像素级走查（交由设计验收） |
| 关键约束验证（降级/越界/上限/隐私/无障碍） | 压力/渗透测试（纯前端低风险，轻量覆盖） |
| 性能预算验证 | 多语言（英文 V1.0）完整测试 |

### 2.3 测试分级策略

| 级别 | 占比 | 工具 | 目标 |
|---|---|---|---|
| 单元测试 | 50% | Vitest | 纯函数/引擎逻辑（布局、笔画路径、数据校验） |
| 集成测试 | 25% | Vitest + fake-indexeddb | 跨模块（引擎↔存储↔状态） |
| E2E 测试 | 15% | Playwright | UI 流程 + 黄金图像/渲染断言 + 零上传隐私 |
| 手动/专项 | 10% | 浏览器实机 | 兼容性、无障碍、性能体验 |

## 3. 测试环境（浏览器矩阵）

| 浏览器 | 版本 | 导出能力 | 备注 |
|---|---|---|---|
| Chrome / Edge | 94+ | WebCodecs H.264 MP4 ✅；MediaRecorder WebM ✅ | 全能力 |
| Firefox（桌面/Android） | 130+ | WebCodecs ❌；MediaRecorder WebM ✅ | **缺 WebCodecs**，走 WebM |
| Safari（桌面/iOS） | 26+ | WebCodecs H.264 MP4 ✅；MediaRecorder MP4(H.264) ✅ | WebM 弱支持，靠 MP4 |

> 该矩阵直接对应 IM-RISK-001 R-02、R-10。测试必须在三者上分别执行导出降级用例。

## 4. 测试框架与基础设施

| 项 | 选型 |
|---|---|
| 单元测试/集成 | Vitest + @fake-indexeddb（IndexedDB 模拟） |
| E2E | Playwright（Chromium/Firefox/WebKit） |
| 契约测试 | Vitest + 接口快照（IM-API-001 §4 接口） |
| 黄金图像 | 固定种子渲染，逐像素比对（容差 2%） |
| 隐私断言 | Playwright `page.on('request')` 过滤，断言无用户数据外发 |
| 无障碍 | axe-core（集成于 Playwright）+ 手动键盘走查 |
| 性能 | Lighthouse CI + 自定义 performance.mark 预算 |

## 5. 关键测试用例（约束 → 用例）

### 5.1 导出降级矩阵 `[IM-RISK-001 R-02/R-10、IM-API-001 §4.4.3]`

| 用例 ID | 场景 | 前置 | 期望 |
|---|---|---|---|
| TC-EXP-01 | Chromium WebCodecs 可用 | 支持 VideoEncoder | 实际格式 = mp4；degraded=false |
| TC-EXP-02 | Safari 26+ WebCodecs 可用 | Safari 26+ | 实际格式 = mp4（H.264） |
| TC-EXP-03 | Firefox 无 WebCodecs | Firefox 桌面/Android | 实际格式 = webm；degraded=true；提示原因 |
| TC-EXP-04 | 不支持任何编码 | 极端环境 | 抛 E-EXPORT-001；提示"浏览器不支持" |
| TC-EXP-05 | 导出取消 | 中途 cancel() | 抛 E-EXPORT-002；无残留 Blob |
| TC-EXP-06 | `transparent=true` 在 MVP/V1.0 | 请求透明 | 字段被忽略；不报错（V2.0 才生效，IM-ARCH-001 AC-07） |

### 5.2 古文字受限字库越界跳过 `[IM-BASELINE-001、IM-API-001 §5.1]`

| 用例 ID | 场景 | 期望 |
|---|---|---|
| TC-CHAR-01 | 古字体选中，文本含字库外字符 | `checkRestrictedChars` 返回越界列表；渲染跳过并触发 `restricted:chars` 事件 |
| TC-CHAR-02 | 内置字体（楷/宋）选中 | `charset` 为空表示全字库；不触发越界 |
| TC-CHAR-03 | 越界字符提示文案 | 文案 = "「{字}」不在{字体}字库内，已跳过"（IM-UI-001 §14.3） |

### 5.3 5000 字上限端到端拦截 `[IM-SRS-001 §3.5、IM-DB-001 DC-06]`

| 用例 ID | 场景 | 期望 |
|---|---|---|
| TC-LIMIT-01 | 输入 5000 字 | 允许保存/预览 |
| TC-LIMIT-02 | 输入 5001 字 | 抛出 E-LAYOUT-001；UI 红框提示"文本超出 5000 字限制，请分段生成" |
| TC-LIMIT-03 | 超限文本导入 | 拒绝并提示；不写入 `projects` 表 |
| TC-LIMIT-04 | 存储校验 | `validateProject` 拦截（IM-DB-001 §9.4） |

### 5.4 笔画三路径渲染一致性 `[IM-TECH-001 §7.1、IM-BASELINE-001]`

| 用例 ID | 场景 | 期望 |
|---|---|---|
| TC-STROKE-01 | 楷体字符 | `strokeSource='hanzi-writer'`；逐笔动画数据完整 |
| TC-STROKE-02 | 宋体字符 | `strokeSource='whole'`；整字显现（非逐笔） |
| TC-STROKE-03 | 古字体字符（字库内） | `strokeSource='skeleton'`；骨架化路径生成 |

## 6. E2E 测试范围

| 流程 | 覆盖 |
|---|---|
| 新建 → 输入 → 预览 → 导出 | 黄金路径（TC-EXP / TC-LIMIT / TC-PRIV 组合） |
| 我的项目 → 打开/重命名/删除 | CRUD |
| 设置 → 参数持久化 | 刷新后保留 |
| 受限字库提示 | 古字体越界交互 |
| 零上传隐私 | 全程网络断言 |

> Canvas/视频渲染的 E2E 最难，E2E 仅覆盖 UI 流程 + 少量黄金图像断言；引擎逻辑靠单测/集成测（IM-PLAN-001 补充建议）。
