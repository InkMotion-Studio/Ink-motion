## 4. 测试环境（V1.0 增量说明）

浏览器矩阵**沿用 IM-TEST-001 §3**（Chrome/Edge 94+、Firefox 130+、Safari 26+），V1.0 增加两条执行要求：

| 新增要求 | 说明 |
|---|---|
| **深色主题必须在三浏览器各跑一遍** | 检查 CSS 变量与 `prefers-color-scheme` 交互是否一致 |
| **字体上传必须在三浏览器各跑一遍** | FontFace 对 woff2/otf 支持与 IndexedDB Blob 存取存在差异；Safari 对 woff2 支持已普遍可用但仍需实测 |

## 7. E2E 扩展范围（V1.0）

| 新流程 | 覆盖 |
|---|---|
| 古文字旅程 | 选古字体 → 输入 → 越界提示 → 渲染 → 导出 |
| 主题旅程 | 切深色 → 刷新保持 → 对比度断言 |
| 语言旅程 | 切英文 → 全站文案 → 刷新保持 → 切回中文 |
| 字体上传旅程 | 上传 → 启用 → 渲染 → 刷新 → 删除 |
| 4K + 队列旅程 | 入队 2 个任务 → 取消 1 个 → 完成 1 个 |
| 零上传强化 | 上述全部旅程统一挂载网络断言 |

> 沿用 IM-TEST-001 §6 的原则：E2E 覆盖 UI 流程与少量黄金图像断言，引擎逻辑仍以单测/集成测为主。
