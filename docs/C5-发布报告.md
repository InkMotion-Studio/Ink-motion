## 4. 部署方式（任选其一）

```bash
npm run build          # 产出 dist/
# GitHub Pages：push 到 main，CI（.github/workflows/deploy.yml）自动发布
# Netlify：拖入 dist/ 或绑定仓库（netlify.toml 已含 SPA 回退）
# Vercel：导入仓库（vercel.json 已含缓存与安全头）
# CF Pages：构建命令 npm run build，输出目录 dist（_headers 自动生效）
```

独立资产 CDN：设置环境变量 `VITE_ASSET_CDN=https://cdn.example.com/` 后重建，
纹理将指向 `${CDN}/inkmotion-assets-v1/textures/*.png`（未配置时使用本域 `/textures/`）。

## 5. 已知边界（不影响 MVP 发布）

- **古文字路径**：阻塞于开源小篆发布（R-01），V1.0 启用；UI 已显式标注。
- **MP4 真机编码**：沙箱无 H.264 编码器；WebCodecs 路径逻辑就绪，自动降级 WebM 兜底，联网 Chromium/Safari 26+ 实测即可确认。
- **跨浏览器**：沙箱仅 Chromium；Firefox 全系走 WebM 保底（代码路径已覆盖）。
- **英文 i18n / 深色主题**：V1.0 计划项，UI 已预留开关占位。
