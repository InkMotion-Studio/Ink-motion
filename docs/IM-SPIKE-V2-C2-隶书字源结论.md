# IM-SPIKE-V2-C2 隶书字源 Spike 结论

**文档编号：** IM-SPIKE-V2-C2
**版本：** v1.0
**状态：** 已完成（TBD-V2-02 闭环）
**编制日期：** 2026-10-14
**上游文档：** IM-PLAN-V2-001 v1.1 §5（N2.1）、IM-GLYPH-V2-001 v1.1 §4、IM-RISK-V2-001 v1.1（VR2-02）

## 1. Spike 目标

依据 IM-PLAN-V2-001 §5 的 N2.1，闭环 **TBD-V2-02（隶书字源合规确认）**，给出隶书路径是否实施、以何种字源实施、以及在"字源二进制未必即时可得"前提下的落地方式。

---

## 2. 决策依据：合规政策 D-V2-02

用户决策（2026-10-14，见 IM-PLAN-V2-001 §8 与 `PENDING-LICENSES.md`）：

> **V2.0 不再以"资源合规性"作为功能阻塞条件**——对评估范围内字源**一律采用**；对需授权/授权状态待确认的字体，统一登记于「字体授权待办登记册」，由权利方后续联系获取正式授权。

据此，VR2-02（隶书字源授权不清）已由「合规·高·阻塞」**降级为「已接受·低」**，TBD-V2-02 **关闭**。

---

## 3. 候选字源评估

| 候选 | 授权 | 覆盖/风格 | 结论 |
|---|---|---|---|
| 开源隶书（各类 OFL / 开放授权隶书字体） | 待核（按 D-V2-02 一律采用并登记） | 真实隶书字形，蚕头燕尾 | **选定方向**（资产待提供） |
| 全字库隶书（若开放授权） | 开放授权 | 覆盖广 | 备选（体积/可得性待核） |
| 系统隶书族（`LiSu` / `STLiti`） | 随操作系统授权 | 现代隶书，风格偏"印刷隶" | **不随包**，仅作字体栈兜底（零成本、零合规风险） |

---

## 4. Spike 结论（TBD-V2-02 闭环）

**结论：采用。** 具体落地方式：

1. **字源方向**：优先采用开源/开放授权隶书字体，登记于「字体授权待办登记册」（`PENDING-LICENSES.md` 第 3 项 + `src/lib/licenses.ts` 的 `pendingAuthorization: true`）。
2. **资产现状**：隶书字体二进制与映射表**尚未随包提供**（与 V2-C1 的 L1 敬峰 / L2 全字库同构）。V2-C2 交付的是**可运行、可验证的隶书管线**：字源就绪时自动生效，资产缺失时**静默跳过该层**并回退到系统隶书族 / 衬线字体栈，**不阻塞、不白屏**。
3. **不造假**：不以内置"伪隶书"或程序化变形冒充真实隶书字形；缺失即如实提示"字表待提供"，复用 V2 全程一致的"资产缺失静默跳过"模式。
4. **字体栈兜底**：即便隶书字体未随包，渲染层仍以 `LiSu → STLiti → 衬线` 兜底，保证隶书路径在任何环境都有可见字形；系统未装隶书族时以衬线呈现（信息性，非错误）。

---

## 5. 实现要点（落地于 N2.2）

| 项 | 方案 |
|---|---|
| 字体枚举 | `FontFamily` / `StrokePathKind` 追加 `'li'`（追加，不替换） |
| 字表/映射 | `seal-map` 同构的 `li-map`（今字→隶书码位）；字表缺失时 `transformToLi` 退化为**恒等映射**（不拦截、不提示越界） |
| 渲染 | 复用受限字库"整字显现"路径（`drawRestrictedGlyph`）；隶书同样**不承诺笔顺** |
| 字体栈 | `getLiFontStack()`：`"LXGW Li"(注册成功时) → "LiSu" → "STLiti" → 衬线` |
| 资产 | `li-font`(woff2) / `li-map`(JSON) / `li-font-fallback`(TTF)，均按需加载、不预缓存 |
| 受限字集 UI | 独立 `LiCharsetPanel`（类前缀 `im-li-panel`）+ `useLiOutOfRange`/`useLiCoverage` |
| 合规 | 一旦取得授权 → 从登记册移除并正式登记 `licenses.ts`（`attributionRequired: true` + 随包许可） |

---

## 6. 风险与残留跟踪

| 风险 | 处置 |
|---|---|
| 隶书字体二进制不可得 | 架构就绪 + 静默跳过 + 系统隶书族兜底；UI 提示"字表待提供" |
| 授权最终无法获得 | 依 D-V2-02，登记册跟踪；发布报告"已知边界"标注"隶书字源授权待确认"，产品保持可用 |
| 隶书单字覆盖不全 | 越界字符走既有 `out-of-range` 跳过 + 提示（与篆书一致） |

> 残留跟踪责任：技术负责人；跟踪方式：`PENDING-LICENSES.md` + 发布报告。
